# Mirko Longhi - Portfolio

Sito statico personale pronto per GitHub Pages.

## Prima della pubblicazione

1. Crea la cartella `assets`.
2. Inserisci il PDF del CV in `assets/mirko-longhi-cv.pdf`.
3. Verifica email, telefono e contenuti dei progetti in `index.html`.
4. Apri `index.html` nel browser per una verifica veloce.

## Pubblicazione su GitHub Pages

1. Crea un repository pubblico su GitHub.
2. Carica `index.html`, `styles.css`, `script.js`, `README.md` e la cartella `assets`.
3. Apri **Settings > Pages**.
4. In **Build and deployment**, seleziona **Deploy from a branch**.
5. Scegli il branch `main` e la cartella `/ (root)`.
6. Premi **Save** e attendi la pubblicazione.

L'indirizzo sarà `https://TUO-USERNAME.github.io/NOME-REPOSITORY/`. Per ottenere `https://TUO-USERNAME.github.io/`, il repository deve chiamarsi esattamente `TUO-USERNAME.github.io`.
